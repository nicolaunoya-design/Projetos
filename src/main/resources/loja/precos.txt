# Preços base da loja do UltraCore (preço de COMPRA de 1 unidade).
# Só os itens "naturais" (minérios, drops de mobs, plantas, blocos do mundo) ficam aqui; todo o resto
# (tábuas, ferramentas, lingotes em bloco, vidro, comidas...) é calculado sozinho pelas receitas do
# próprio servidor (bancada, fornalha, cortador e mesa de ferraria). Preço de venda = % do painel.
#
#   nome valor             -> compra e venda
#   nome valor venda       -> só dá para VENDER (não aparece para comprar)
#   nome valor compra      -> só dá para COMPRAR (a loja não compra de volta)
#   nome valor semreceita  -> só vale se o item não tiver receita nesta versão (senão usa a receita)
#   nome nao               -> fora da loja
#   padrão = ingrediente [ingrediente...] [+valor]   -> vale o mesmo que os ingredientes (+ extra)
# "*" funciona como curinga (ex: *_spawn_egg). Nomes que não existem na versão do servidor são ignorados.
