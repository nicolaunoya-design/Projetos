# Projetos

Modelos 3D para trabalhos da escola, prontos para imprimir.

| Pasta | Matéria | O que tem |
|---|---|---|
| [`modelos_3d/`](modelos_3d/) | Biologia | interior do espermatozoide e do óvulo, em corte (8 cm) |
| [`fisica_polia_alavanca/`](fisica_polia_alavanca/) | Física | polia fixa + polia móvel e alavanca (gangorra de moedas), que funcionam de verdade |

Cada pasta tem os arquivos STL, imagens de como fica, um guia de impressão (`README.md`)
e o script que gera os modelos.
